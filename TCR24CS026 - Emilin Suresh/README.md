# Capability Embedding for Capability Composition

## Overview

This project implements a feature-based vector embedding approach for representing states, goals, and executable capabilities. It explores how capabilities can be compared, checked for functional compatibility, and combined into a sequence to achieve a goal.


## Objectives

* Represent application states and goals as feature vectors.
* Encode capabilities using their inputs, outputs, preconditions, effects, and operational properties.
* Calculate cosine similarity between capability embeddings.
* Evaluate whether two capabilities are functionally compatible.
* Explore the composition of multiple capabilities.
* Evaluate alternative implementations, goal relevance, and operational properties.

## Technologies Used

* C++
* Standard Template Library (STL)
* GCC / MinGW
* Visual Studio Code

## Experiments

1. **Compatibility:** Compare compatible and incompatible capability pairs.
2. **Composition:** Check whether capabilities can be connected into a sequence.
3. **Alternative implementations:** Compare API, database, and GUI implementations.
4. **Goal relevance:** Examine whether capabilities contribute to a specified goal.
5. **Operational properties:** Compare execution time, resource cost, monetary cost, risk, reliability, and availability.

Experiment results are stored in the `results/` directory when generated by the program.

## Compilation and Execution

Open a terminal in the project root directory and run:

```powershell
g++ -std=c++17 -static-libgcc -static-libstdc++ -Iinclude src/main.cpp src/State.cpp src/Goal.cpp src/Capability.cpp src/Embedding.cpp src/Similarity.cpp src/Compatibility.cpp src/Composer.cpp -o capability_embedding_static.exe
```

Run the compiled program:

```powershell
.\capability_embedding_static.exe
```

## Testing

Compile the test program separately:

```powershell
g++ -std=c++17 -static-libgcc -static-libstdc++ -Iinclude tests/test_embedding.cpp src/State.cpp src/Goal.cpp src/Capability.cpp src/Embedding.cpp src/Similarity.cpp src/Compatibility.cpp src/Composer.cpp -o test_embedding.exe
```

Then run:

```powershell
.\test_embedding.exe
```

## Limitations

The implementation uses manually designed feature vectors and compatibility rules. Its results depend on the chosen features, weights, and thresholds; it is not a pretrained language model.
