# Vector Embedding for Capability Composition

## Assignment 2

This project implements a problem-specific vector representation for formally specified states, goals, and executable capabilities.

## Application Domain

**Online Shopping / E-Commerce**

## Objective

The objective of this project is to represent states, goals, and capabilities as vectors while preserving useful relationships for capability compatibility, composition, goal relevance, and operational properties.

## Main Features

- State encoding
- Goal encoding
- Capability encoding
- Cosine similarity calculation
- Capability compatibility checking
- Capability composition
- Goal relevance analysis
- Operational attribute representation
- Experimental dataset generation

## Capabilities

The project contains the following e-commerce capabilities:

1. AddToCart
2. CheckInventory
3. CreateOrder
4. MakePayment
5. GenerateInvoice
6. SendNotification
7. CancelCart
8. UpdateProfile

## Experiments

The implementation performs five experiments:

1. Capability Compatibility
2. Capability Composition
3. Alternative Implementations
4. Irrelevant Capabilities
5. Operational Attributes

### Capability Compatibility

Tests whether capabilities can be executed sequentially based on their preconditions and effects.

### Capability Composition

Evaluates the composition:

CreateOrder → MakePayment → GenerateInvoice

### Alternative Implementations

Compares API, Database, and GUI implementations of the same functionality.

### Irrelevant Capabilities

Compares relevant and irrelevant capabilities with respect to the target goal.

### Operational Attributes

The representation includes:

- Cost
- Reliability
- Availability
