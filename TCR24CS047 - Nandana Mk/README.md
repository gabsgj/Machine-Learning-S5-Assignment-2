## Project Overview

This project presents a feature-based Capability Embedding framework for AI Planning. The system represents capabilities as numerical feature vectors and evaluates their relationships using similarity metrics. It supports capability compatibility analysis, capability composition, alternative implementations, irrelevant capability detection, and operational attribute comparison.

The project demonstrates how AI planning capabilities can be encoded into embedding vectors for efficient comparison and analysis.

---

## Objectives

- Represent capabilities using feature embeddings.
- Encode capabilities into numerical vectors.
- Measure similarity between capabilities.
- Perform capability composition.
- Compare alternative implementations.
- Detect irrelevant capabilities.
- Evaluate operational characteristics such as execution time and reliability.
- Visualize experimental results using graphs and heatmaps.
