# Submission Checklist

Before submitting the GitHub link in Google Classroom:

- [ ] Push the complete repository to GitHub.
- [ ] Make sure the repository is accessible to your teacher.
- [ ] Open the GitHub link in an incognito/private browser and confirm it works.
- [ ] Confirm `src/capability_embedding.py` is present.
- [ ] Confirm `src/run_experiments.py` is present.
- [ ] Confirm `dataset/capability_dataset.csv` is present.
- [ ] Confirm `report/PCCST503_Assignment2_Technical_Report.md` is present.
- [ ] Confirm `results/experiment_results.csv` is present.
- [ ] Run the tests:
  `python -m unittest discover -s tests -v`
- [ ] Run the experiments:
  `python src/run_experiments.py`
- [ ] Paste only the repository URL into Classroom if Classroom asks for a link.
