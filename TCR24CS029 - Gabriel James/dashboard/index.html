Plan view

Background machinery: the planner searches the application's state space towards a goal. It is shown for completeness and is outside the Assignment 2 evaluation scope, which covers compatibility, mapping, adapters and the runtime.

Bundle builder

Assembles a self contained copy of the system (modules, specs, gateway binary, dashboard and start scripts) under the chosen directory, default dist/careweave-mini. Untick modules or workflows to trim the bundle; a module a shipped workflow binds is added back automatically and reported below.
