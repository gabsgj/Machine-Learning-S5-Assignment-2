# Formal embedding design

## 4. Proposed representation

Enumerate the Cartesian product of all variable domains in sorted variable order: Omega={s_1,...,s_N}. Global policy violations yield zero transition rows. The state basis is shared by states, goal masks and capability operators within one application schema. Port signatures, atomic mechanisms and resources have sorted finite vocabularies built from the dataset.

For an atomic capability, form an N by N matrix F_i. An applicable source state has a single 1 in the column for its deterministic successor; an inapplicable state has an all-zero row. This captures negative conditions, numeric bounds, frame persistence and assignments without a learned approximation. flatten(F_i) is a vector in R^(N squared).

The full vector concatenates the transition block, input indicators, output indicators, mechanism indicators or counts, resource indicators, and seven operational values. Mechanism features encode the formal type and a canonical JSON mechanism. A composite sums mechanism counts and unions resources. Metadata retains interface declarations for readable diagnostics; the finite interface vocabulary also permits recovery of selected declarations from the indicator blocks.

## 5. Mathematical formulation

State: phi_S(s_k)=e_k in R^N, a row-basis vector. Goal: phi_G(G)=g in {0,1}^N where g[k]=1 iff s_k satisfies every goal condition. Thus phi_S(s) dot g is the exact goal truth value.

Let B_i(s) be the conjunction of P_i, K_i and the global policy K. Let f_i(s) apply E_i by overriding named variables. Define F_i[k,l]=1 iff B_i(s_k), K(f_i(s_k)) and f_i(s_k)=s_l; otherwise it is 0. Availability, resource presence and input values are intentionally outside this structural operator. Each row sum is 0 or 1.

Capability: phi_C(C_i)=[vec(F_i),u_I,u_O,h_M,h_R,q]. If L is the port vocabulary size, H the mechanism vocabulary size and J the resource vocabulary size, d_C=N^2+2L+H+J+7. The seven q entries are time_ms, resource_cost, money, risk, energy, reliability and availability. Raw units are preserved for accounting; use block selection rather than unscaled whole-vector cosine for functional judgments.

Functional similarity is sigma(i,j)=<vec(F_i),vec(F_j)>/(||F_i||_F ||F_j||_F), or 0 if a norm is zero. It is symmetric resemblance, not an execution test. State overlap can change this measure: identical effects with different guards need not score 1. The full-vector distance detects mechanism and quality differences; no capability-name-only coordinate is added.

For directional compatibility, a_i=F_i 1 and b_ij=F_i F_j 1. State coverage kappa(i,j)=sum(b_ij)/sum(a_i), with 0 for an empty denominator. An output matches an input iff names and type labels agree and the output domain is a subset of the input domain. D_ij=1 iff every required downstream input has such an upstream output.

Guaranteed structural compatibility is sum(a_i)>0 AND kappa=1 AND D_ij=1. Existential compatibility is sum(b_ij)>0 AND D_ij=1. These quantify over all modeled applicable source states, not only reachable states. The strict pair test requires upstream outputs to provide downstream inputs. A composition may instead expose missing inputs externally; the two interfaces answer different questions.

Goal relationship: V(C,s,G)=phi_S(s) F_C phi_G(G), in {0,1}. It tests structural success of a given capability or sequence; it is not a planner or a reliability estimate. Execute separately enforces operational gates. In the supplied chain, a capability's contribution is assessed by removing it from the fixed sequence and reevaluating V.

## 6. Capability composition model

compose([C_1,C_2,...,C_m]) executes left to right, representing C_m o ... o C_1. Decode each transition block, multiply F_comp=F_1 F_2 ... F_m, and flatten the result. This is a bilinear composition operation on the matrix blocks of two encoded vectors, rather than ordinary vector addition.

Proof of exactness: an applicable first row is e_l for its unique successor s_l. Multiplying that row by F_2 selects the unique successor row of s_l. If either step is inapplicable the resulting row is zero. Induction extends the claim to every finite sequence. Matrix multiplication is associative and generally noncommutative. A wholly zero composite is rejected as having no valid initial state.

Interface composition processes each input against accumulated outputs. Compatible outputs bind internally. A required input with no preceding output becomes an external input. A same-name, incompatible output raises an error. Accumulated outputs persist, with latest-name overwrite. The composite stores remaining external inputs and all retained outputs. This is a contract abstraction: actual output values are not generated by the specification simulator.

Time, money, resource cost and energy sum for serial execution. Reliability multiplies under independent success assumptions. Aggregate risk is 1-product(1-risk_i), also assuming independent adverse events. Availability is logical AND and resource requirements are union. Correlated failures, consumable capacities and time-varying availability are not modeled. Risk and reliability are separate estimates and need not be complements.

Execution of a composite uses its transition matrix, retained input contract and aggregated gates. Composition is therefore possible structurally even when current availability makes execution impossible. Encoded composites can be passed back to encode or nested in compose. Associativity is checked on the full vectors for the supplied chains; arbitrary conflicting external port contracts require a richer binding model.
